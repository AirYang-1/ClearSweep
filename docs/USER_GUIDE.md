# ClearSweep 使用说明

## 1. 下载与启动

从 [官方 Release](https://github.com/AirYang-1/ClearSweep/releases/latest) 下载 **ClearSweep.exe**，双击即可运行。

- 支持 Windows 10/11 x64，系统需 .NET Framework 4.8。
- Python、Qt 和操作引擎已经包含在 EXE 内，无需额外安装这些开发环境。
- 打开时按 Windows 提示确认管理员权限。启动卡片显示真实阶段与等待动画，主界面显示后再读取软件清单。
- 可以单独移动这个 EXE；外观和备份数据保存在当前用户的 `%LocalAppData%\ClearSweep`。

校验文件：在 EXE 所在目录的 PowerShell 中运行 `Get-FileHash .\ClearSweep.exe -Algorithm SHA256`，与同一 Release 的 `SHA256SUMS.txt` 对照。

## 2. 查看、搜索与导出软件

左侧“软件管理”包含应用程序、驱动与运行库、系统组件、隐藏项目、最近安装和商店应用六种筛选。

顶部输入名称或发布者关键字进行搜索；通过列表右上角切换名称、体积、发布者或日期排序。选中一项后，右侧显示版本、路径、日期依据和登记来源，并提供打开目录、复制命令和审阅残留。

顶部导出按钮把**当前筛选结果**保存为 CSV；选择保存位置后，可用 Excel 查看中文列名和内容。

“估算体积”是软件报告的数值，可能缺失；日期带 `*` 表示卸载登记更新时间参考，不代表首次安装时间。“最近安装”包含近 30 天安装或维护记录。

同名但版本、路径或卸载命令不同的登记会保留。系统组件、隐藏项目及受保护记录默认只读；“32 位登记来源”不等于程序本身一定是 32 位。

## 3. 卸载软件

1. 选中目标软件，检查右侧的软件名、版本和安装位置。
2. 点击“卸载软件”，在确认框检查卸载命令。
3. 确认后，ClearSweep 启动该软件原有的卸载程序。按原卸载器的提示完成操作。
4. 等待卸载程序及可跟踪的辅助进程结束。确认软件已移除后，程序刷新清单并询问是否查看关联残留。
5. 选择查看后进入“残留审阅”，继续检查和勾选。取消提示不会删除内容。

卸载失败会显示错误码或详细原因；取消卸载不会自动清理。提示需要重启时，按原卸载器提示处理，再重新检查。

## 4. 审阅与清理残留

可以在应用详情点击“审阅残留”，或在成功卸载后的提示中进入。

- 先检查完整路径、关联依据和风险提示。关联目录不一定是残留，候选项默认不勾选。
- 文件目录需要自行勾选，再点“移入回收站”。确认框列出项目数、估算大小和路径；确认后执行，取消不处理。
- 共享目录、系统路径、链接和其他受保护项目仅供查看。
- 孤立卸载登记单独处理：点击“移除孤立登记”，核对目标，程序先导出 `.reg` 备份，再移除这一条记录。
- 注册表清理仅限能够明确判断已孤立的卸载登记，不是全盘注册表清理。

文件回收失败时，可以复制错误详情，处理文件占用或权限问题后刷新重新审阅。已经成功回收的项目保留在回收站，未完成项目保留原位。

## 5. 管理启动项

进入左侧“启动管理”，选择当前用户项目，点击“备份并禁用”。确认后，原注册表值或快捷方式会保存到 ClearSweep 的用户备份区。

恢复时选择已禁用项目，点击“恢复启动入口”。如果原位置已经有同名项目，程序停止恢复并保留备份，避免覆盖。

本版本管理 Run 注册表项和 Startup 文件夹快捷方式。系统范围项目只读；暂不管理服务、计划任务或浏览器扩展。

## 6. 外观与快捷键

左下角“外观设置”提供烟黑紫、冰川蓝、深林青、琥珀金、玫瑰粉和石墨银六套主题。

可以调整窗口不透明度、玻璃面板浓度、光效强度和颜色；也可以切换界面动效、玻璃柔光与紧凑列表。设置即时保存，启动卡片在下次打开时同步主题与颜色。主题支持导入、导出和恢复默认。

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+F / Ctrl+K | 返回软件管理并聚焦搜索 |
| F5 | 刷新当前页面 |
| Ctrl+, | 打开外观设置 |

顶部空白区域可以拖动窗口；双击顶部空白区可以最大化或还原。窗口位置会按单个显示器的可用区域保存和恢复。

## 7. 恢复与数据位置

| 内容 | 恢复方式或位置 |
| --- | --- |
| 已回收的文件或目录 | 打开 Windows 回收站，选择对应项目并还原 |
| 孤立登记备份 | `%LocalAppData%\ClearSweep\Backups`；核对相应 `.reg` 后使用 Windows 导入 |
| 已禁用启动项 | 优先在 ClearSweep 中恢复；备份位于 `%LocalAppData%\ClearSweep\DisabledStartupV2` |
| 外观配置 | `%LocalAppData%\ClearSweep\appearance.json` |
| 软件图标缓存 | `%LocalAppData%\ClearSweep\IconCache` |

请保留注册表和启动项备份目录，以便恢复。本版本不提供无提示批量卸载、商店应用强制删除或驱动级安装过程跟踪。

问题反馈可到 [Issues](https://github.com/AirYang-1/ClearSweep/issues)，附上版本、Windows 版本和错误详情；分享截图或日志前请检查其中的私人路径和信息。
